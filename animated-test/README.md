# ReST-Lake Animated Test

Experimental visual clone of `memory-baseline-test/calibration/`.

Only UI changes: an animated skin, live DOM-state indicators and same-origin iframe resizing. All original model, validation, download, calibration, and notebook scripts are copied unchanged by Git blob SHA. Production paths are untouched.

Open `https://khanzainub.github.io/thermal-memory-lake-temperature-model/animated-test/`.

Animations respect prefers-reduced-motion, and can be paused individually within model modules.
