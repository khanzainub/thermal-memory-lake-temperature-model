05

Calculate and save lake calibration value

One reusable value per lake: Mean bias = average of (in-situ temperature − satellite LST) across all matched historical observations. A value estimated from 2018 can be saved and applied to later years without recalculating it, assuming the sensor and systematic bias remain stable. Corrected satellite LST = original satellite LST + saved bias (°C). No missing dates are filled. Different measurement dates can represent actual temperature change.
