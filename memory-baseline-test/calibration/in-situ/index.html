05

Calculate and save lake calibration value

One reusable value per lake: Combine all available genuine in-situ/satellite matched dates, including observations in different years, and calculate bias = mean(in-situ temperature − satellite LST). Save this single lake-specific offset and reuse it for any other satellite period, provided the systematic bias is reasonably stable. Corrected satellite LST = original satellite LST + saved bias (°C). No observations are fabricated or interpolated.
